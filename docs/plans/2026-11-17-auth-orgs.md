# Auth, super admin, organizations & invitations (Phase 1a-auth)

Part of `2026-11-17-b2b-dpdpa-platform.md`. Consent module re-scoping to orgs is the NEXT PR (1a-consent).

## Decisions (user)
- Own auth: email + password (argon2id via `@node-rs/argon2`), no external IdP.
- Fixed org roles: `org_admin`, `privacy_officer`, `editor`, `auditor`, `viewer`.
- Super admin = platform only (create/suspend orgs, invite first org admin). Tenant data only via
  time-limited, reason-required, **read-only** break-glass session logged in the org's audit chain.
- 2FA later.

## Tokens
- Access: HS256 JWT, 15 min, claims `sub`(user id) `typ:"access"` `aud:"dpdpa-app"` `iss` `iat` `exp`.
  Org is NOT in the token: `/orgs/{orgId}/…` routes load membership per request so role changes/removals apply instantly.
- Refresh: opaque 32-byte token, stored as sha256, httpOnly cookie `dpdpa_rt` (Path=/auth, SameSite=Strict, Secure in prod),
  30 days, rotated on every use; reuse of a rotated token revokes the whole family.
- Password change / disable → all refresh families revoked; access tokens issued before `password_changed_at` rejected.
- Legacy consent JWTs (`role` claim) keep working on consent routes until 1a-consent; the two token types reject each other.

## Tables (`db/schemas/auth/index.ts`)
users · organizations · memberships (unique org+user) · invitations (sha256 token, 7-day expiry, one pending per org+email) ·
refresh_tokens (family, used_at, revoked_at) · break_glass_sessions. `audit_log.org_id` nullable (NULL = platform chain).

## Endpoints
- `/auth`: POST login, refresh, logout · GET me · POST password
- `/invitations`: GET preview?token · POST accept
- `/platform/organizations` (super admin): POST create (+ first org_admin invite), GET list, PATCH {id}/status,
  POST {id}/break-glass, DELETE {id}/break-glass/{sessionId}
- `/orgs/{orgId}`: GET, PATCH · `/members`: GET, PATCH {userId}, DELETE {userId} · `/invitations`: POST, GET, DELETE {id}
- Guards: last active org_admin can't be demoted/removed; suspended org → 403 for members.

## Security
Generic login errors; dummy argon2 verify when user unknown; lockout 5 failures → 15 min. Audit payloads carry ids/roles only (no emails).
Mailer interface: `memory` (tests), `console` (dev); production refuses `console`.
